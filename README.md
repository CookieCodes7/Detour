# PuzzleVerse

Vite + React + Tailwind v4 + React Router + Framer Motion.

    npm install
    npm run dev          # http://localhost:5173
    npm run build
    npm run check-links  # pings every game URL (needs open internet)

Add games in `src/data/games.js` (one row each). Categories, filters, search, daily row and random picker all read from it.
